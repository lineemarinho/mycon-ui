@mycon/ui

Design system compartilhado do backoffice Mycon. Os 16 componentes abaixo cobrem toda a lista de prioridade alta e média encontrada na auditoria dos 11 repositórios backoffice-*-front — ver AUDITORIA.md e DECISIONS.md.

Button

Ações

Botão de ação primária, secundária ou de baixa ênfase. Espelha a API já adotada via MyconButtons nos 11 repos (variant/size/isLoading) para minimizar esforço de migração.

Evitar quandoA ação é apenas um ícone dentro de uma lista densa — nesse caso, use um botão de ícone dedicado com Tooltip.

IconActionButton

Ações

StatusBadge

Feedback

Indicador de status por semântica de cor. Substitui os 3 padrões concorrentes achados na auditoria (StatusBadge/StatusChip custom, StatusTag, "dot" inline com hex divergente entre repos).

Evitar quandoA cor não representa um dos 5 status semânticos — nesse caso, o status provavelmente precisa ser remapeado, não um novo hex criado.

ConfirmDialog

Feedback

Modal de confirmação genérico sobre Dialog do MUI. Substitui as 4+ reimplementações manuais do shell de modal (posicionamento via transform) encontradas na auditoria.

Usar quandoUma ação destrutiva ou irreversível precisa de confirmação explícita (cancelar, excluir, encerrar).
Evitar quandoO conteúdo do modal tem múltiplos campos de formulário — nesse caso é um modal de formulário, não uma confirmação.
