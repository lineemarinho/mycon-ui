mycon-ui

Design system compartilhado do backoffice Mycon, publicado como pacote privado no GitHub Packages.

Instalação

1. Crie um .npmrc na raiz do seu projeto apontando o escopo @mycon para o GitHub Packages (o token precisa do escopo read:packages):

// .npmrc @mycon:registry=https://npm.pkg.github.com //npm.pkg.github.com/:_authToken=${GITHUB_TOKEN}

2. Instale o pacote e suas peer dependencies:

npm install mycon-ui @mui/material @mui/icons-material @emotion/react @emotion/styled

3. Importe os componentes direto do pacote:

import { Button, Input } from "mycon-ui"; <Button variant="secondary" tone="success"> Confirmar </Button>
